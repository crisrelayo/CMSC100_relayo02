To create deploy your own repository follow these steps.
First, go into the settings of your repository.
Then, click the pages tab on the left side.
Afterwards, change the branch to main.
Wait for a few minutes for Github to verify.
In the code tab of the repository, click github-pages.
Click the link and you're done.

In this exercise, I learned how to create a static page in HTML and CSS with the application of Flexbox. I also learned how to deploy the page in my own public github repo and view it live.
